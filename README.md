## 🎮 Welcome to the Arena!

Tired of boring exam preparation?

Welcome to **PYQ Battle**, where learning meets competition!

PYQ Battle is an interactive exam preparation platform designed to make practicing Previous Year Questions (PYQs) and preparing for exams more engaging and enjoyable.

Whether you're revising concepts, testing your knowledge, or challenging yourself with questions, the Exam Arena is your place to sharpen your skills and prepare for the real battle.

**Your mission is simple:**
- 📚 Practice smarter.
- 🧠 Strengthen your concepts.
- ⚡ Challenge your knowledge.
- 🏆 Become exam-ready!

## 🚀 Getting Started

Want to explore the project locally? Follow these steps!

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

And you're inside the arena! 🎮
